# 매장 대기 순번 시스템

손님이 매장의 QR코드를 찍으면 휴대폰 브라우저로 대기번호를 받고, 관리자는 `/admin` 화면에서 호출·완료를 처리합니다. 앱을 설치할 필요가 없습니다.

- 손님 화면: `http://서버주소:8000/`
- 현황판(TV): `http://서버주소:8000/board`
- 관리자 화면: `http://서버주소:8000/admin`

> 이 폴더는 GitHub Pages(정적 사이트)에서는 실행되지 않습니다. `app/templates` 안의 HTML 파일을 더블클릭해서 여는 것도 동작하지 않습니다. 반드시 아래처럼 서버를 켠 뒤 브라우저 주소창에 주소를 입력해서 접속합니다.

## 0. 가장 쉬운 방법 (Windows)

1. 파일 탐색기에서 `queue` 폴더의 **`start.bat`** 을 더블클릭합니다.
2. 처음 한 번은 필요한 프로그램을 자동으로 설치하고, 관리자 비밀번호를 물어봅니다.
3. 검은 창에 아래처럼 접속 주소가 나옵니다. 이 창을 닫으면 서버가 꺼지니 켜두세요.
   ```
     손님 접수      http://192.168.0.10:8000/
     현황판(TV)     http://192.168.0.10:8000/board
     관리자         http://192.168.0.10:8000/admin
   ```
4. 같은 와이파이에 연결된 휴대폰·TV·태블릿의 브라우저 주소창에 이 주소를 입력합니다. 서버 PC에서는 `http://localhost:8000` 으로도 열립니다.

**바탕화면 바로가기 (이 PC에서 바로 열기)**

```bash
.venv\Scripts\python scripts\make_shortcuts.py
```

바탕화면에 `대기순번 - 손님 접수`, `대기순번 - 현황판(TV)`, `대기순번 - 관리자` 바로가기 3개가 생깁니다. 더블클릭하면 서버가 꺼져 있을 때 자동으로 켜고(작업표시줄에 최소화된 창), 브라우저로 해당 화면(`http://localhost:8000/...`)을 엽니다. 최소화된 서버 창을 닫으면 사이트도 꺼집니다.

Python이 없으면 https://www.python.org/downloads/ 에서 설치하세요. 설치 화면에서 "Add python.exe to PATH" 를 꼭 체크해야 합니다. 아래 1~3번은 직접 명령어로 실행하는 방법입니다.

## 1. 설치 (처음 한 번)

Python 3.10 이상이 필요합니다. `queue` 폴더에서 실행합니다.

```bash
python -m venv .venv
```

```bash
.venv\Scripts\activate
```
(macOS/Linux: `source .venv/bin/activate`)

```bash
pip install -r requirements.txt
```

## 2. 관리자 비밀번호 설정

`.env.example` 파일을 복사해서 `.env` 파일을 만들고 값을 바꿉니다.

```bash
copy .env.example .env
```

| 항목 | 설명 |
|---|---|
| `ADMIN_PASSWORD` | **필수.** 관리자 로그인 비밀번호. 비어 있으면 관리자 화면에 로그인할 수 없습니다. |
| `SECRET_KEY` | 로그인 상태 유지용 비밀키. 비워두면 서버를 재시작할 때마다 다시 로그인해야 합니다. `python -c "import secrets; print(secrets.token_hex(32))"` 로 만들어 넣으세요. |
| `STORE_NAME` | 화면 상단에 표시할 이름 |
| `RETENTION_DAYS` | 이 일수가 지난 접수의 이름·전화번호 뒷자리를 자동으로 지웁니다(기본 30일). 통계용 숫자는 남습니다. |
| `PUBLIC_URL` | 현황판 QR코드에 넣을 손님 접속 주소. 비우면 서버 PC의 IP로 자동 설정됩니다. |
| `DATABASE_URL` | 기본은 이 폴더의 `queue.db` (SQLite) |

`start.bat` 이나 `python run.py` 로 처음 실행하면 비밀번호를 물어보고 `.env` 를 자동으로 만들어 줍니다. `.env` 와 `queue.db` 는 git에 올라가지 않도록 `.gitignore` 에 들어 있습니다. 비밀번호를 바꾼 뒤에는 서버를 다시 시작하세요.

## 3. 실행

```bash
python run.py
```

- 같은 PC에서는 `http://localhost:8000` 으로 열립니다.
- 손님 휴대폰은 **같은 와이파이**에 연결된 상태에서 `http://PC의IP:8000` 으로 접속합니다. PC의 IP는 `ipconfig` 의 "IPv4 주소"로 확인합니다.
- Windows 방화벽 창이 뜨면 "개인 네트워크"에서 허용해주세요.
- 종료는 `Ctrl+C` 입니다.

## 4. QR코드 만들기

```bash
python scripts/make_qr.py http://192.168.0.10:8000/ -o 매장QR.png
```

주소는 실제 손님이 접속할 주소로 바꾸세요. PC의 IP가 바뀌면(공유기 재시작 등) QR코드도 다시 만들어야 하니, 공유기에서 PC에 고정 IP를 지정해두는 것을 권장합니다.

## 5. 사용 방법

**손님**
1. QR코드 스캔 → 이름(한글 2~4자)과 전화번호 뒷 4자리 입력 → 대기번호 발급
2. 내 번호 화면에서 대기 순서 확인. **"호출 알림 소리·진동 켜기"** 를 한 번 눌러두면 호출 시 소리와 진동이 울립니다. 휴대폰 브라우저는 사용자가 화면을 한 번 눌러야 소리를 낼 수 있습니다. iPhone은 진동을 지원하지 않습니다.
3. 화면을 닫았다가 다시 QR을 찍거나 주소를 열어도 내 번호 화면으로 돌아옵니다.

**관리자**
- **호출**: 손님 화면이 주황색으로 바뀌고 알림이 울립니다.
- **완료**: 처리 완료. 대기 목록에서 내려갑니다.
- **노쇼 / 건너뛰기**: 호출 후 오지 않는 손님을 처리합니다(호출 전이면 "건너뛰기").
- **되돌리기**: "오늘 처리 내역"에서 실수로 처리한 손님을 대기 목록으로 되돌립니다.
- **접수 마감하기 / 재개하기**: 마감 중에는 손님 화면에 마감 안내가 나오고 새 접수가 막힙니다.

대기번호는 매일 자정(한국 시간)에 1번부터 다시 시작합니다.

**현황판 (TV)**: `http://서버주소:8000/board`
- 로그인 없이 볼 수 있습니다(이름은 가려서 표시).
- 왼쪽에 **지금 호출된 번호**(가장 최근이 크게), 오른쪽에 **대기 목록**과 **접수용 QR코드**가 나옵니다. 마감 중에는 QR 대신 마감 안내가 나옵니다.
- 화면을 **한 번 클릭**(TV 리모컨의 확인 버튼)하면 새로 호출될 때 "딩동" 소리와 함께 "○번 고객님, 순서입니다" 안내 음성이 나옵니다. 브라우저 정책상 한 번 눌러야 소리가 납니다.
- **더블클릭이나 F 키**를 누르면 전체 화면이 됩니다. 마우스를 가만히 두면 커서가 사라집니다.
- TV에서 보려면 스마트TV 브라우저로 주소를 열거나, 서버 PC를 HDMI로 TV에 연결해 크롬에서 열면 됩니다. 관리자 화면 상단의 "현황판 열기" 버튼으로도 열 수 있습니다.

**접속 주소·QR 모음**: 관리자 화면 상단의 "접속 주소·QR" 버튼(`/admin/links`)
- 손님 접수·현황판·관리자 주소 3개와 각각의 QR코드를 한 장에 보여주고, [인쇄하기]로 출력할 수 있습니다.
- 주소는 서버 PC의 현재 IP로 자동으로 만들어지니, **매장 와이파이에 연결한 상태에서** 열어야 맞는 주소가 나옵니다.

## 6. 개인정보

- 손님 화면에는 이름이 가려져서(김○수) 표시되고, 전화번호는 아예 보내지 않습니다. 원본은 관리자 화면에서만 보입니다.
- `RETENTION_DAYS` 가 지난 기록은 서버가 켜져 있는 동안 6시간마다 자동으로 이름·전화번호를 지웁니다(서버 시작 시에도 1회 실행).

## 7. 인터넷에 공개하려면

매장 와이파이 밖에서도 접속하게 하려면 Render, Fly.io, 클라우드 VM 같은 곳에 올리고 **HTTPS** 로 서비스하세요. 이때 다음 사항을 지켜야 합니다.
- 시작 명령: `uvicorn app.main:app --host 0.0.0.0 --port $PORT --timeout-graceful-shutdown 2`
- 환경변수 `ADMIN_PASSWORD`, `SECRET_KEY` 를 호스팅 설정 화면에서 지정
- SQLite 파일이 재배포 때 지워지지 않도록 영구 디스크를 쓰거나 PostgreSQL(`DATABASE_URL`)로 전환
- 실시간 알림(SSE)이 메모리 기반이라 **서버 프로세스는 1개**로 실행하세요(workers 1).

## 폴더 구조

```
app/
  main.py       라우트(손님·현황판·관리자·SSE)
  services.py   접수·검증·마스킹·상태변경·통계·개인정보 삭제
  models.py     DB 테이블 (queue_entries, settings)
  db.py         DB 연결 (SQLite 동시 접수 잠금 처리)
  auth.py       관리자 로그인 쿠키 · CSRF
  events.py     실시간 변경 알림(SSE)
  netinfo.py    접속 주소(PC의 IP) 계산
  templates/    화면 HTML
  static/       CSS, JS, 로고
scripts/make_qr.py   QR코드 생성
scripts/make_shortcuts.py  바탕화면 바로가기 3개 만들기
scripts/open_page.py       바로가기가 실행: 서버를 켜고 화면 열기
run.py               실행 스크립트 (접속 주소 출력, 처음 실행 시 비밀번호 설정)
start.bat            Windows에서 더블클릭으로 실행
tests/               자동 테스트
```
